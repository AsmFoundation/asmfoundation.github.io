AsmSdk

Released 0.4.02026-11-26

Assembly projects on MSBuild and NuGet

Features

  • .asmproj next to .csproj, built with dotnet build
  • NASM for x64, GNU syntax for ARM64, LLVM's for WebAssembly
  • Windows, Linux and macOS on x64 and ARM64, and WebAssembly for browsers and WASI
  • C# bindings and a C header from each function's PROTO line
  • The assembler and linker restore from NuGet
