Benchmarks

The measurements behind our claims, drawn. Each chart names the run it comes from, and one core sits next to many. The CRC-32C charts set every language at its best against the assembly, C#, Go, JavaScript, Python and Rust so far, and show where assembly loses as well as where it wins. Next: the other kernels, and C++, Java and Zig (the plan).

Here the languages that inline the checksum win: the assembly is a library, and each call also pays a jump and size checks that inlined code skips, which at 64 bytes cost more than the checksum itself. Bytes allocated per call: JavaScript 16 (it boxes the 32-bit result), every other entry 0; Python's are not counted.
